# Scripts to evaluate the TE polymorphic detection programs (computation of TP and FP)

## `test_position_ref.pl` 

It compares the positions of insertions detected by polymorphic TE detection programs and the positions of the reference insertions, making sure that the name of the copy is indeed in the complete simulated chromosome produced by ReplicaTE, to compute the number of True and False positives

**Dependencies**

perl 5, version 30, subversion 0 (v5.30.0)

**Usage**

```
perl test_position.pl --in1 annot_TEs_simul_genome.tsv --in2 <filename> --in3 annot_TEs_del_1.tsv --out <filename> --bp <int>
```

*Mandatory options*

```
--in1 file containing the TE annotations from the complete simulated chromosome generated by replicaTE (annot_TEs_simul_genome.tsv) 
--in2 file containing the prediction of reference insertions for a given tools (format: chromosome,TEname,type of insertion,start,stop,strand) 
--in3 file containing the TE annotations from the deleted simulated chromosome generated by replicaTE (annot_TEs_del_1.tsv) 
--out output file 
--bp margin of error in bp 
```

## `test_position_nonref.pl` 

It compares the positions of non-reference insertions detected by polymorphic TE detection programs and the expected positions of the non reference insertions in the deleted simulated chromosome produced by ReplicaTE

**Dependencies**

perl 5, version 30, subversion 0 (v5.30.0)

**Usage**

```
perl test_position_nonref.pl --in1 <filename> --in2 <filename> --out <filename> --bp <int>
```

*Mandatory options*
```
--in1 file containing the non-reference TE annotations with coordinates relative to the deleted simulated genome 
--in2 file containing the prediction of non-reference insertions for a given tools (format: chromosome,TEname,type of insertion,start,stop,strand) 
--out output file 
--bp margin of error in bp 
```

## `FP_TP_teflon_insertion.py`

This script allows to compute the TP, FP and FN TE insertions detected by TEFLoN on short read sequencing data with a vcf file obtained from variant calling analysis on long read data from the same sample on the same reference genome. The two analyses are both compared to a reference TE annotation file. 

**Usage**
```
python3 FP_TP_teflon_insertion.py -nbed non-ref_${prefix}.genotypes.bed -rbed ref_${prefix}.genotypes.bed -vcf INS_ERV_${sample}_variants.vcf -ref BT-ERV_copies_repbase_annotation_sorted.bed -prefix ${sample}
```

Usage is reminded when typing:

```
Python3 FP_TP_teflon_insertion.py -h, --help
```

*Mandatory options*
```
-nbed Input BED file including coordinate results of the non-reference insertions
-rbed Input BED file including coordinate results of the reference insertions
-vcf Input VCF file including insertion variants
-ref Input BED file including the TE insertion annotations in the reference genome
-prefix Sample prefix for the output file names
```

**Outputs**
```
    • ${prefix}_new_true_positives.bed, file containing the coordinate of the true positive non-reference insertions (non-reference insertions identified in the short and long reads)
    • ${prefix}_new_false_positives.bed, file containing the coordinate of the false positive non-reference insertions (non-reference insertions identified in the short reads but not the long reads)
    • ${prefix}_new_false_negatives.vcf, file containing the false negative non-reference insertions (non-reference insertions identified in the long reads but not the short reads)
    • ${prefix}_ref_true_positives.bed, file containing the coordinate of the true positive reference insertions (reference insertions identified in the short and long reads)
    • ${prefix}_ref_false_positives.bed, file containing the coordinate of the false positive reference insertions (reference insertions identified in the short reads but not the long reads)
```
